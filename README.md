# Prompt Playground

An interactive Prompt Engineering application that demonstrates how different prompting techniques influence the responses generated by Large Language Models (LLMs).

Users can enter a question, choose a response style, and observe how different prompt engineering strategies produce different types of responses.

---

## Features

- Interactive Streamlit web interface
- Three response styles:
  - Quick Answer
  - Learn with Example
  - Detailed Explanation
- Prompt Routing
- Template-based Prompt Generation
- Optimized Prompt Visualization
- Google Gemini 2.5 Flash Integration
- Modular Python Architecture
- Single API Call per Request

---

## Prompting Techniques

| Response Style | Prompting Technique | Description |
|---------------|---------------------|-------------|
| Quick Answer | Zero-shot Prompting | Generates a concise answer without examples. |
| Learn with Example | Few-shot Prompting | Uses an example to guide the response style. |
| Detailed Explanation | Chain-of-Thought Prompting | Produces a structured, step-by-step explanation. |

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Saloni-0414/prompt-playground.git
```

### 2. Navigate to the project

```bash
cd prompt-playground
```

### 3. Create a virtual environment

```bash
python3 -m venv venv
```

### 4. Activate the virtual environment

**Linux / macOS**

```bash
source venv/bin/activate
```

**Windows**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## How It Works

1. Enter your question.
2. Select a response style.
3. The Prompt Router selects the appropriate prompting technique.
4. The Prompt Builder generates an optimized prompt using reusable templates.
5. The prompt is sent to Google Gemini.
6. The generated response is displayed along with:
   - Selected Response Style
   - Prompting Technique
   - Optimized Prompt
   - Final Response
